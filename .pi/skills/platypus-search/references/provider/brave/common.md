# Brave 常用参数

- `--query "关键词"`: 搜索词, 映射为上游 `q`。
- `--count 5`: 网页结果数量。
- `--country US`: 国家代码, `US` (美国) 或 `CN` (中国)。
- `--search_lang en`: 搜索语言, `en` (英语); 中文代码请先按 Brave 官方语言列表核对, 不猜作通用的 `zh`。
- `--freshness pw`: 时间范围, `pd` (近 1 天)、`pw` (近 7 天)、`pm` (近 31 天)、`py` (近 365 天)。
- `--result_filter web`: 结果类型, 常用 `web` (网页)、`news` (新闻); 多类型用逗号分隔。
